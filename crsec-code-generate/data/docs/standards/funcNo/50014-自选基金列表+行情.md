
# 50014 获取自选基金列表（带行情）

::: info 版本兼容
新一代 APP：5.0.8 
:::

## 使用示例
```  js
import { openAction } from '@crsec/tiny-utils'

// callbackName 可以为自定义的任何名称，提供给 native 进行回调
window.callbackName = (res) => {
    let decodedStr = atob(res)
    let decodeData = {}
    try {
        decodeData = JSON.parse(decodedStr)
        // do something
    }cache(e){
        // 处理 JSON 解析异常
    } finally {
        window.callbackName = null
    }
}

/**
 * http://action:50014/?funcType=基金类型&&returnType=基金子类型&&sortDirection=基金排序方向&&sortField=基金排序字段&&JsFuncName=H5回调函数
 * 基金类型：0：全部，1：基金（公募），2：高端理财（私募）
 * 基金子类： 0: 全部，1：股票，2：混合，3：指数，4：债券，5：货币，6：QDII
 * 排序方向：0：降序，1：升序，2：水平（用默认排序--添加时间）
 * 排序字段：0：时间，1：净值，2：添加后收益；3：日涨幅，4：近一周涨幅，5：近一月涨幅，6：近3月涨幅，7：近6月涨幅，8：今年涨幅，9：近1年涨幅，10：近2年涨幅，11：近3年涨幅，12：近5年涨幅，13：成立以来涨幅
 */
openAction(`http://action:50015/?`, {
    funcType: 0,
    returnType: 0,
    sortDirection: 2,
    sortField: 0,
    JsFuncName: 'callbackName'
})

```

## 返回值类型

``` js
{
    code: String,    // 结果代码，0表示成功
    msg: String,     // 错误信息，如参数解析失败，基金代码为空
    data: String     // 基金行情信息，具体字段根据6000044、6000065确定，
}
```
