# 50016 PDF阅读&下载

::: info 版本兼容
新一代 APP：5.0.10
:::

## 接口文档
[App内pdf打开&分享封装](http://confluence.crsec.com.cn/pages/viewpage.action?pageId=61216963)

### pdf 下载&分享

    http://action:50016/?&&tztfiletype=pdf&&url=${fileUrl}

### pdf页面打开接口
    http://action:10054/?tztfiledata=sContent&&title=%E6%B5%8B%E8%AF%95pdf%E5%90%8D%E7%A7%B0&&tzttitle=%E6%B5%8B%E8%AF%95pdf%E5%90%8D%E7%A7%B0&&tztshare=1&&extURL=http://action:50016/?&&tztfiletype=pdf&&url=https://fileview-t.crsec.com.cn/fastdfsview/group1/M00/00/88/CgAQ32bzb5yAOBPuAAMC-eFBOyQ167.pdf

## 使用示例

```js
import { downloadPDF, openPDF } from '@crsec/tiny-utils'

// 阅读PDF
openPDF(pdfurl, title)
// 阅读PDF、同时带下载按钮可保存PDF
downloadPDF(pdfurl, title)
```
