# 50019 期权交易开关

新一代 APP：待定
:::

## 接口文档

* H5调Native路由
    * http://action:50019/?status=1&&JsFuncName=H5回调函数
    * status：是否打开期权开关，0：关闭，1：打开
    * JsFuncName：结果回调函数
* Native调H5 JS：
    * JS拼接：JsFuncName + && + JsFuncName + '(' + '结果数据' + ')'
    * 结果数据：JSON（实际为Base64编码之后的字符串，参考照片选择）
        * code: String        // 调用结果代码，0表示成功
        * status: String      // 操作后期权开启状态，1：开启，0：未开启

## 使用示例

```js
import { openAction, tztGetLocalData } from '@crsec/tiny-utils'

// 获取当前开关状态
const status = await tztGetLocalData('TZTOPTIONTRADEON')

// 修改期权开关状态
openAction(`http://action:50019/?status=${期权开关状态}`)

```
