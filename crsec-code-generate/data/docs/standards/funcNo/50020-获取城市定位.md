# 50020 获取城市定位

::: info 版本兼容
新一代 APP：6.0.2
:::

## 接口文档

- H5调Native路由
  - http://action:50020/?message=xxxx&&JsFuncName=H5回调函数
  - message: 非必填，获取权限展示给用户的弹窗文案
  - JsFuncName：结果回调函数
- Native调H5 JS：

  - JS拼接：JsFuncName + && + JsFuncName + '(' + '结果数据' + ')'
  - 结果数据：JSON（实际为Base64编码之后的字符串，参考照片选择）

  ```js
  {
    code: String // 调用结果代码，0表示成功
    data: {
      cityCode: String // 城市代码
    }
  }
  ```

## 使用示例

```js
import { getCity } from '@crsec/tiny-utils'

// 获取当前开关状态
const cityCode = await getCity()
```
