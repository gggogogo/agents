# 50021 手机号加密

::: info 版本兼容
新一代 APP：6.0.4
:::

## 接口文档

- H5调Native路由

  - http://action:50021/?phoneNum=XXXXX&&JsFuncName=H5回调函数
  - phoneNum：手机号
  - JsFuncName：结果回调函数

- Native调H5 JS：

  - JS拼接：JsFuncName + && + JsFuncName + '(' + '结果数据' + ')'
  - 结果数据：JSON（实际为Base64编码之后的字符串，参考照片选择）

```js
{
  code: String // 调用结果代码，0表示成功
  phoneNumMD5: String // 手机号加密后的MD5值
}
```

## 使用示例

```js
import { openAction, nativeCB } from '@crsec/tiny-utils'

openAction('http://action:50021/?', {
  phoneNum: '13800138000',
  JsFuncName: nativeCB((data) => {
    console.log(data)
  }),
})
```
