# 12051 跳转个股详情

## 功能说明

跳转个股详情页面

## 接口说明

```js
T.fn.changeurl('http://action:12051/?stockcode=' + stockCode + '&&market=' + market)
```

## 参数说明

- stockcode: 股票代码
- market: 行情市场
- sectionId: 个股详情页下方 tab 对应 id
- sectionParams: 透传至个股详情页下方 tab 对应链接的参数
