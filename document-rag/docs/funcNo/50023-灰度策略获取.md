# 50023 灰度策略获取

::: info 版本兼容
新一代 APP：6.0.5
:::

## 接口文档

- H5调Native路由
  - http://action:50023/?bizid=xxxx&&JsFuncName=H5回调函数
  - bizid: 必填，业务id
  - JsFuncName：结果回调函数
- Native调H5 JS：

  - JS拼接：JsFuncName + && + JsFuncName + '(' + '结果数据' + ')'
  - 结果数据：JSON（实际为Base64编码之后的字符串，参考照片选择）

  ```js
  {
    code: String // 调用结果代码，0表示成功
    data: {}
  }
  ```

## 使用示例

```js
import { openAction, nativeCB } from '@crsec/tiny-utils'

openAction('http://action:50023/?bizid=xxxx', {
  JsFuncName: nativeCB((data) => {
    console.log(data)
  }),
})
```
